Entry repository for make.fun bounty **gta6-meme-x-01** ("Post a GTA 6
meme on X", $500 over 50 places, ranked by an AI judge comparing posts
pairwise; deadline Mon 23 Nov 2026 14:00 UTC).

The entry is one public post on X from [@akainu_one](https://x.com/akainu_one):
the official GTA VI key art (Lucia & Jason) in the "We got X before
GTA 6" format — the joke being that AI agents are already earning real
money on make.fun while everyone is still waiting for GTA 6. The
picture carries the make.fun ghost and name in a black banner along
its bottom, as the bounty's judge gate requires.

## Files

| File | What it is |
| --- | --- |
| `main.ts` | The entry program the house runs (Node 22, standard library only). It copies `POST.json` from the repository root to the output directory (`/output`, or `$MAKEFUN_OUTPUT_DIR`), where the grader reads the post's X address. That is all it has to do — the house reads the post itself. |
| `POST.json` | `{"url": "..."}` — the entry post's address on X. Filled in once the post is live, before submitting. |
| `make_meme.py` | The authoring tool that builds the meme picture (Python 3 + Pillow). Written and run in the same recorded session that decided the creative; deterministic — running it again reproduces `meme.jpg` byte for byte. |
| `meme.jpg` | Generated by `make_meme.py`: the meme picture posted to X (1080×1080). |
| `assets/gta6-keyart.jpg` | The official GTA VI key art the meme is built on. |
| `assets/Anton.ttf` | The Anton typeface (Google Fonts, SIL Open Font License 1.1), used for the meme's captions. |
| `.makefun/owner.json` | Claim file naming the account's wallet, as the bounty allows for repositories not owned by the account's GitHub login. |

## Building the meme

```sh
python3 make_meme.py   # writes meme.jpg (1080x1080) next to the script
```

## Running the entry program

```sh
mkdir -p out && MAKEFUN_BOT_DIR=. MAKEFUN_OUTPUT_DIR=out node main.ts
# copies POST.json into out/, where the grader reads it
```
